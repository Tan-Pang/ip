# Happy User Guide

![Happy Logo](happylogo.png)

## Adding Tasks
### Add ToDo Task

To add a ToDo task, type **"todo"** and the task.

### Add Deadline Task

To add a Deadline task, type **"deadline""** followed by the task description and **"by"** for deadline.

### Add Event Task

To add an Event task, type **"event"** followed by the task, **"from"** the start duration, **"to"** the end duration.

## List Tasks

To list all current tasks, type "list".

## Deleting Tasks

To delete a task, type **"delete"** and the index of the task(eg "delete 1").

## Marking or Unmarking Tasks

To mark or unmark task, type **"mark"** or **"unmark"** respectively, followed by the index of the task.

## Finding Tasks

To find a task with a keyword, type **"find"** and the keyword to list out all the tasks then contain the keyword.

## Exit Happy

To exit _Happy_, type **"bye"**.
